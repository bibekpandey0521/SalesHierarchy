# DishHome branding assets

Drop the approved official files here. The application reads them automatically.

Required files:

- `dishhome-logo.png` (or `dishhome-logo.svg`) — official DishHome logo, transparent background preferred.
- `dishhome-banner.jpg` (or `dishhome-banner.png`) — approved dashboard banner.

Do not draw, stretch, recolour or invent these assets. If a file is missing, the UI
falls back to a neutral brand mark and text banner.

Recommended sizes:

- Logo: at least 240 px wide, height 48–72 px.
- Banner: 1600 × 400 px or wider, 4:1 ratio.
